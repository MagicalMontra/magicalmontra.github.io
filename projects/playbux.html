Professional multiplayer work

Playbux Multiplayer Systems

Server-authoritative multiplayer engineering for an MMO-oriented Unity project using C#, Mirror and a heavily modified UDP transport layer.

Role

As a Senior Software Engineer, I owned implementation work across server-authoritative gameplay systems and multiplayer state management.

Area of Interest

I designed and implemented a custom grid-based Area of Interest system integrated with Mirror. The server spatially partitioned the world, determined player visibility and selectively synchronized only the relevant network state to each client.

World state │ ▼ Spatial grid │ ▼ Nearby / relevant entities │ ▼ Per-client visibility │ ▼ Selective network replication

Authoritative movement

Player movement remained server-authoritative while the client predicted local movement for responsiveness. Authoritative server state was used for reconciliation and correction.

Other server-side systems

The multiplayer work also included player spawning, combat and shared world-state systems. The implementation sat on top of Mirror and a substantially modified UDP transport layer.
